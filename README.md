# Furry Roguelike Platformer

- 2D platformer
  - like mario since I like mario
  - convenient since I use a laptop with no mouse (and also like controllers)
- room-based roguelike
  - like tboi/spelunky
  - also has the benefit of short rounds (= short respawn times) and no long-term progression (pick up for a 30m session and get the full experience), which is something I liked from CS:GO
- customizable furry player character
  - like atlyss
- multiplayer support
  - I like playing with friends
  - optional since I have no friends
- unique guns and trinkets that you collect throughout your run
- Godot
