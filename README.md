# tower defense

https://x.com/ChrstmasCracker/status/1499505973177860099

- playable on laptop with no mouse
- roguelike elements with no long-term progression (pick up for a 30m session and get the full experience)
- unique towers
- towers are placed on a grid because I don't like having to micromanage tower positions
- Godot

four base tower types
- cannon (short range single target)
  - upgrades to get a second barrel and then becomes a gatling gun
- sniper (long range single target)
  - upgrades to railgun https://preview.redd.it/medium-should-get-a-railgun-for-season-4-if-it-is-sci-fi-or-v0-536ffi7cbhnd1.jpeg?width=1080&crop=smart&auto=webp&s=b446677aa0d562fd8fd48bb3dc74cc94916dffec
- omnigun (short range AOE)
  - upgrades to become either tesla tower (multiple hits per hit), a fire tower (applies burn effect), or an ice tower (applies freeze effect)
- mortar (long range AOE)
  - upgrades to get a gets a rocket

the fun of tower defense is in the breadth of choices, so distinct upgrade paths
are a must, making sure that there are synergies and no one best strategy/playstyle.
do you choose to upgrade your cannon or buy an omnigun :think:
