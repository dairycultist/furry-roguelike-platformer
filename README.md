# tower defense

https://x.com/ChrstmasCracker/status/1499505973177860099

- playable on laptop with no mouse
- roguelike elements with no long-term progression (pick up for a 30m session and get the full experience)
- unique towers
- towers are placed on a grid because I don't like having to micromanage tower positions
- Godot

four base tower types
- cannon
  - upgrades to get a second barrel and then becomes a gatling gun
- mortar
  - upgrades to get a gets a rocket
- tack-shooter type thing
  - upgrades to become either tesla tower (multiple hits per hit) or fire tower (applies burn effect)
- sniper

the fun of tower defense is in the breadth of choices, so distinct upgrade paths are a must, making
sure that there are synergies and no one best strategy/playstyle
